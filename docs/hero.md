# Первый экран Siberian Marketing

Статическая страница для GitHub Pages: `index.html`, `assets/styles/main.css`, `assets/scripts/`. Сборка и зависимости не нужны. Настройки публикации не менялись. Пути относительные, включая размещение по `/sv/`.

Локальный запуск из корня: `python3 -m http.server 8000`. Открыть страницу через HTTP, чтобы работали JS-модули.

## Подключение контента

- Telegram: указать реальный HTTPS-адрес `t.me` или `telegram.me` в `siteConfig.telegramUrl` в `assets/scripts/config.js`. До этого основная кнопка отключена с пояснением.
- Кейсы: в отдельной задаче добавить реальный раздел `id="cases"` после Hero. Кнопка активируется при загрузке страницы только при наличии раздела; плавная прокрутка учитывает `prefers-reduced-motion`. Если нужен другой ID, обновить `casesSectionId`.
- Фото: добавить оптимизированный портрет в `assets/images/` и заполнить `siteConfig.portrait` объектом `{ src, alt }`. Фото занимает зарезервированную область без сдвига макета. До успешной загрузки остаётся фирменная типографическая композиция; случайных фотографий и broken-image placeholder нет.

## Визуальная основа

Палитра — рабочая, не окончательная. Все основные цвета в `:root`; композиция не зависит от конкретного акцентного цвета. Локальный вариативный Golos Text с кириллицей, лицензия SIL OFL в `assets/fonts/OFL.txt`. Запросов к Google Fonts нет.

Иерархия: специализация → основной заголовок → путь до посещения → пояснение → действия → опыт. На мобильном опыт идёт перед дополнительной визуальной областью. Статистика — только предоставленные пользователем данные; схема пути не представляет вымышленные результаты или конверсию.

UI UX Pro Max использован для рекомендаций по типографике, иерархии и адаптивности; Impeccable — для контроля качества. Тексты и надпись над заголовком из задания имеют приоритет над общими ограничениями навыков. Финальная визуальная концепция оставлена открытой по указанию пользователя; дополнительных этапов её утверждения в этой реализации нет.

## Проверено

- Chromium: 320, 390, 768, 1440 и 1920 px — без горизонтального переполнения; desktop/mobile просмотрены визуально.
- Единственный h1 и единственный раздел Hero; клавиатурная ссылка пропуска навигации переводит фокус на main.
- Без настроек CTA отключены. Временные браузерные фикстуры подтвердили активацию Telegram и переход к существующему разделу кейсов; фиктивные адреса и разделы в проект не записаны.
- При ошибке загрузки фото сохраняется типографическая замена. Снижение движения отключает плавную прокрутку. Ошибок JavaScript при проверках нет.
- Основные текстовые пары имеют контраст не менее 5.36:1. Замечания Impeccable по мелким подписям и контрасту исправлены; независимый визуальный reviewer подтвердил устранение обрезанной точки монограммы на мобильных экранах.
- Проверка синтаксиса JS прошла; общий размер HTML и assets около 81 КБ, без внешних библиотек и внешних запросов страницы.
