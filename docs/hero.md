# Siberian Marketing: Hero, версия по референсам

Реализован только первый экран. Статический HTML/CSS и JavaScript-модули, без сборки, бэкенда, трекеров и зависимостей. Настройки GitHub Pages не меняются. Все пути относительные и работают при размещении в `/sv/`.

Локальный запуск из корня: `python3 -m http.server 8000`.

## Текущая композиция

Тёмный фон, светлая типографика, сине-фиолетовая световая дуга за портретом и полупрозрачная схема «Заявка → Запись → Посещение». Пять референсов пользователя трактуются как направление вкуса, не копируются как готовые макеты. Цвета собраны в `:root` файла `assets/styles/main.css`; это текущая версия, не окончательное утверждение палитры.

Согласованные тексты и показатели опыта сохранены. Личного имени, отзывов, кейсов и результатов, которых пользователь не предоставлял, нет.

## Контакты и расширение

- Реальный HTTPS-адрес Telegram добавляется в `assets/scripts/config.js`, поле `telegramUrl`. До этого кнопка отключена, рядом есть объяснение. Некорректные адреса не активируют её.
- Кнопка кейсов активируется только при наличии реального раздела `id="cases"`. Раздел добавляется после Hero отдельной задачей; ID можно изменить через `casesSectionId`. Плавная прокрутка отключается при `prefers-reduced-motion`.
- Новые блоки добавляются в `main` после Hero; общие цвета, шрифт, ширина контейнера и стили кнопок уже выделены.

## Анимация

- Короткое появление текста и портрета при загрузке.
- Два прохода светового импульса по пути до посещения, всего менее пяти секунд; это схема процесса, а не данные о заявках.
- Смещение портретной сцены максимум на 4 px по горизонтали и 3 px по вертикали при движении мыши. На touch-устройствах отключено, бесконечного requestAnimationFrame-цикла нет.
- Системная настройка уменьшения движения отключает анимации и плавную прокрутку, включая переключение настройки во время просмотра. Без JavaScript текст, фото и показатели остаются доступны.

## Изображения и шрифты

Портрет предоставлен пользователем как `IMG_8864.HEIC`; фон удалён инструментом редактирования изображений с инструкцией сохранить внешность. WebP-версии имеют ширину 640/1000 px и занимают примерно 52/120 КБ. Исходный HEIC и промежуточные изображения не входят в репозиторий. Метаданные исходной фотографии удалены при экспорте; происхождение и инструкция обработки записаны в `assets/images/provenance.json`.

Golos Text (кириллица и латиница) размещён локально; лицензия SIL OFL — `assets/fonts/OFL.txt`. Страница не обращается к Google Fonts или другим внешним сервисам.

## Проверки

Chromium: 320, 390, 768, 1024, 1440, 1920 px; проверены загрузка фото, переполнение, семантика одного Hero, клавиатурная ссылка пропуска навигации, reduced-motion, отключённые кнопки и их активация на временных браузерных фикстурах. Ошибок JavaScript и внешних запросов страницы не обнаружено.

UI UX Pro Max: использованы рекомендации по стеклянным поверхностям, контрасту, адаптивности и движению. Результат общего поиска, предлагавший брутализм, не принят: он не соответствует референсам пользователя.

Impeccable: один запуск detector. Замечания `dark-glow` относятся к намеренному свету из референсов; `border-accent-on-rounded` — к декоративной дуге, не к карточке. Статическое замечание `tiny-text` для относительного `.66em` проверено в браузере: реальные вычисленные размеры текста не меньше 12 px. Автоматические замечания не объявляются отсутствующими; их контекст проверен вручную.
