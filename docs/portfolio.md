# Опыт, кейсы и отзывы

Раздел `#cases` продолжает существующий Hero: тот же Golos Text, тёмный фон,
лавандовый акцент, контейнер и система отступов. HTML/CSS и небольшой JS-модуль;
новых библиотек, настроек Pages и серверных компонентов нет.

## Обновление

Данные: `data/portfolio.json`. После изменений запустить:

```sh
python3 scripts/build-portfolio.py
```

Генератор изменяет только область между `portfolio:start` / `portfolio:end`
в `index.html`. GitHub Pages отдаёт уже готовый HTML; Python на хостинге не нужен.
Без JavaScript доступны цифры, все отзывы, обычные ссылки на VK и аудиоплееры.
JS добавляет вкладки, просмотр медиа, кнопки галереи и однократные появления.
В первых двух кейсах результат и отзыв переключаются вкладками; в кейсе
Коноплёва показатели и цитата видны одновременно, что меняет ритм раздела.

## Недостающие файлы

Inline-изображения видны в чате, но не доступны как скачиваемые файлы
в рабочей среде. Вёрстка не подменяет их нарисованными рекламными кабинетами.
Для завершения доказательной части нужны оригиналы JPG/PNG или ZIP:

- Скриншоты кабинетов: 2, 5, 7, 8, 10.
- Переписки: 6, 12, 14, 15, 16.
- Скрины 1, 4, 9, 11 уже использованы как источник периода и описания;
  их старый дизайн воспроизводить не нужно.
- Реальные обложки двух видео. VK недоступен для скачивания из среды
  (HTTP CONNECT 403); воспроизведение у посетителя зависит от VK и его сети.
  Проверка локального интерфейса не доказывает доступность ролика у VK.
- Точные текстовые расшифровки обоих аудио для посетителей, которые не могут
  прослушать запись (WCAG 1.2.1). Средств распознавания речи в среде нет;
  цитаты из переписок не выдаются за расшифровки аудио. Полное соответствие
  раздела требованиям доступности по этому критерию пока не заявляется.

Пустые элементы `evidence` и `image: null` намеренны. На странице нет битых
картинок, вымышленных скриншотов, фиктивных кнопок просмотра оригиналов.
Когда файлы предоставлены, положить их в `assets/images/cases/` или
`assets/images/reviews/`, указать данные и снова запустить генератор:

```json
{
  "src": "./assets/images/cases/real-file.webp",
  "alt": "Рекламный кабинет проекта: период и результат",
  "width": 2048,
  "height": 1094
}
```

Объект добавляется в массив `evidence` кейса или поле `image` отзыва.
Появляется вкладка «Доказательства» либо оригинал переписки. Изображение
можно увеличить в диалоге и открыть в отдельной вкладке. `video.poster`
принимает путь к реальному кадру ролика. Содержание источников не изменять;
разрешены обрезка лишнего интерфейса и сжатие без изменения смысла.

## Проверка

Проверять вкладки мышью, Tab, стрелками, Home/End; Escape и возврат фокуса
после медиа; свайп и кнопки галереи; раскрытие данных компактных кейсов.
Без JavaScript контент остаётся доступен. При reduced motion анимаций нет.
Все пути к локальным ресурсам относительные и подходят для GitHub Pages `/sv/`.

Публикация содержимого на `main` разрешена владельцем. Незавершённая часть —
добавление оригиналов изображений и реальных видеообложек из списка выше.
