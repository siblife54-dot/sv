# Skills для этого репозитория

- Используйте локальный `ui-ux-pro-max` (`.agents/skills/ui-ux-pro-max/SKILL.md`) при проектировании дизайн-системы, выборе стиля, типографики, композиции и адаптива. Его комплектные вспомогательные Skills подчиняются тому же порядку работы.
- После разработки используйте локальный `impeccable` (`.agents/skills/impeccable/SKILL.md`) для `critique`, `audit` и `polish`.
- Согласовывайте рекомендации: требования пользователя и принятая дизайн-система проекта имеют приоритет. Impeccable проверяет реализацию этой системы; не вводите параллельные токены и противоположные стилистические правила. Конфликт фиксируйте и разрешайте до изменения интерфейса.
- Hooks не подключены. Не включайте их автоматически и не отключайте sandbox или подтверждения действий. Для Impeccable live обязательно задавайте `IMPECCABLE_LIVE_COPY_AGENT=chat` (или `off`), чтобы исключить автоматический запуск агента с обходом защиты. Сам live запускайте только по запросу пользователя.
- Установка Skills не разрешает разработку сайта или изменение настроек GitHub Pages. Такие изменения выполняйте только в отдельной задаче.
- Инструкции проверки и обновления: `docs/agent-skills.md`. Не коммитьте кэши, временные файлы и скачанные бинарники.
